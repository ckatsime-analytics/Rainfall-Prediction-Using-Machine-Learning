## 🌧️ Rainfall Prediction Using Machine Learning
## Objective
To develop a machine learning model that predicts rainfall occurrence based on meteorological features such as atmospheric pressure, dew point, humidity, cloud cover, sunshine hours, wind direction, and wind speed. The project emphasizes robust preprocessing, exploratory analysis, and Random Forest classification with hyperparameter tuning to achieve balanced accuracy and generalization on unseen data.

## Project Workflow
Data Preparation: Cleaning, handling missing values, encoding categorical variables, and balancing classes.

Exploratory Data Analysis (EDA): Statistical summaries, distributions, correlation matrix, and outlier detection.

Modeling: Random Forest classifier with hyperparameter tuning to reduce overfitting.

Evaluation: Accuracy ~0.79–0.81 with balanced precision/recall.

Deployment: Defined prediction function, demonstrated usage with sample input, and saved model for reuse.

## Results
Achieved strong predictive performance with balanced metrics.

Improved generalization after tuning, ensuring practical usability.

Ready for integration into weather forecasting applications.
